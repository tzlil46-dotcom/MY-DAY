My Day - Privacy Policy

Last updated: November 25, 2026

Overview

My Day is a personal productivity application for managing tasks, nutrition, workouts, shopping lists and calendar events.

Google Calendar Data

My Day requests read-only access to Google Calendar to display calendar event titles, dates and times. The application does not create, modify or delete Google Calendar events.

Data Storage

Personal application data is stored locally in the user's browser. Calendar event information may be cached locally on the device. Google OAuth access tokens are kept temporarily in memory and are not stored in local storage. Google Calendar data is excluded from exported application backups.

Data Use and Sharing

Google Calendar data is used solely to provide calendar display functionality. My Day does not sell Google user data, share it with advertisers, or transfer it to an application-owned server. The application communicates with Google services to retrieve authorized calendar information.

Google API Compliance

My Day's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

User Control and Data Deletion

Users can revoke calendar access through their Google Account security settings. The application's disconnect feature removes locally cached calendar information. Local application data can also be deleted by clearing the application's browser site data.
